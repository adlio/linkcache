## [0.1.1] - 2025-01-04

### Added

- Initial release of the linkcache library
- Browser link caching with support for Firefox, Chrome, and Arc
- SQLite-backed cache with full-text search (FTS) for fast link queries
- Firefox bookmarks and history import
- Chrome bookmarks and history import
- Arc browser sidebar and history import
- Alfred workflow integration for quick link searching
- Configurable cache builder for customizing browser sources
